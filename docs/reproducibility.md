# Phase 10: Testing and Reproducibility

```bash
python scripts/reproduce.py --verify     # ~4 min: verifies the committed frozen state end to end
python scripts/reproduce.py --list       # every pipeline step, raw archive -> final evaluation
python -m pytest                         # 133 tests
```

## 1. What "reproducible" means here

| Level | Guarantee | How it is checked |
|---|---|---|
| **Data split** | regenerated **bit-identically** from the raw Kaggle archive (seeded; whole question-graph components) | `make_splits.py` re-derives the split and compares per-split id hashes with `split_metadata.json` |
| **Frozen models and thresholds** | the exact artifacts that were evaluated are versioned in git and hash-checked | `artifacts/phase8/freeze_manifest.json` and `artifacts/MODEL_REGISTRY.json` |
| **Inference** | deterministic: the same input gives the same score, decision, cluster and signals | golden outputs (`tests/golden/expected_scores.json`), checked to 1e-5 |
| **Reported test results** | recomputable from the saved per-pair test scores with the frozen thresholds | `reproduce.py --verify` → `verify_test_results()` |
| **Retraining from scratch** | every step is scripted and ordered; **bit-identical weights are not guaranteed** | see §4 |

`reproduce.py --verify` on the committed state (`artifacts/logs/phase10_verify.log`):

```

[freeze] existing split found -> reproduced exactly
[verify] freeze manifest: OK
[verify] test metrics recomputed from saved scores: final F1 0.78559 = reported, PR-AUC 0.83355 = reported, ... (all match)
[verify] summary: registry ✓, freeze_manifest ✓, test_results_recomputed ✓, split_reproduces ✓, tests ✓
```

## 2. Versioned artifacts

**Model registry** (`artifacts/MODEL_REGISTRY.json`, built by `scripts/build_registry.py`): 22 artifacts, each with phase, role, whether the final
system uses it, content SHA-256, size, whether git tracks it, and the command that regenerates it. It also records the software environment
(Python 3.12.2; numpy 2.5.3, pandas 2.2.2, scikit-learn 1.9.1, scipy 1.18.1, torch 2.14.1+cpu, sentence-transformers 6.1.0, transformers 5.18.0,
streamlit 1.64.0).

| Category | Artifacts | In git? |
|---|---|---|
| **Final system** (decision path) | MLP head `mlp.pt` + `mlp_config.json`; meta-model `meta_model.joblib`; threshold policies; configs | **yes**: a fresh clone runs the final system and the demo after downloading the pinned encoder |
| Encoder | `sentence-transformers/all-MiniLM-L6-v2` pinned to **revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`** (`configs/models.yaml`); weights SHA-256 equals the Phase 8 freeze manifest | downloaded from the Hugging Face Hub |
| Clustering model | `centroids.npy` (frozen; K-Means refits are not bit-reproducible) + metadata + post-hoc names | yes |
| Vectorisers / tokenizers | BiLSTM vocabulary (`vocab.json`, tracked); TF-IDF vectoriser inside `lr_tfidf_*.joblib` | vocab yes; TF-IDF no (large) |
| Reference models | Phase 2 TF-IDF LRs (6–8 MB), BiLSTM weights (35 MB) | no: hashed in the registry, regenerated by `reproduce.py` |
| Feature configuration | `artifacts/feature_config.json`: chosen variant, feature groups, **design columns in order**, canonicalisation rules, threshold | yes (generated from the frozen model) |
| Data-derived files | raw data, split CSVs, embedding caches, feature CSVs | no: regenerated from the archive (the split's hashes are in git) |

**Phase 10 fix.** Before this phase, the base model's MLP head (`mlp.pt`, 776 KB), on which the final system depends, was git-ignored by the generic
`*.pt` rule, so a fresh clone could not run the final system without retraining Phase 3. It is now versioned, together with the two tiny LR heads.
A test enforces that every final-system artifact is git-tracked.

## 4. Retraining from scratch: what to expect

`python scripts/reproduce.py --from extract --to calibration` re-runs Phases 1–7 in order (about 6–8 h on a laptop CPU; times in `--list`).
Some outputs will differ slightly from the committed ones:

| Step | Bit-identical? | Why not |
|---|---|---|
| Split, audit, lexical features, constraint features | **yes** | deterministic, seeded |
| TF-IDF / logistic regression baselines | yes (in practice) | deterministic solvers |
| Encoder embeddings | to float16 precision | encoder numerics depend on batch composition; values are cached as float16 |
| MLP head, BiLSTM, cross-fitted folds | **no** (close) | multithreaded float reductions in PyTorch; seeds fix initialisation, not summation order |
| K-Means | **no** (refit ARI ≈ 0.9997 vs frozen) | multithreaded float32 reductions; this is why centroids are frozen and `build_clusters.py` refits only with `--refit` |
| HistGradientBoosting meta-model | yes, given identical inputs | seeded; Phase 8 found and fixed input-representation sensitivity |

Retraining would therefore change the hashes in the Phase 8 freeze manifest, and with them the evaluated system. **The committed frozen artifacts are the
source of truth for every reported number;** `--verify` proves they are intact and that the reported results follow from them. The test split was
evaluated once (`TEST_EVALUATED.json`); `final_evaluation.py` refuses to re-run, and re-evaluating would require a new held-out set.

## 5. Environment

- CPU only (no CUDA required; `get_device()` uses CUDA automatically if present). Developed on Windows 11, Python 3.12.2.
- `pip install -r requirements.txt`. The CPU PyTorch wheel is installed with `--index-url https://download.pytorch.org/whl/cpu`.
- spaCy (`en_core_web_sm`) is needed only to reproduce the Phase 6 NER ablation; the final system is spaCy-free.
- The first run downloads the pinned MiniLM encoder from the Hugging Face Hub (about 90 MB).
